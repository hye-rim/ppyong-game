# 뿅뿅 블록 🟣

같은 색 블록을 모아 터뜨리는 60초 퍼즐. [작은 오락실](https://github.com/hye-rim/smallgame)의 게임 중 하나. 의존성 없는 정적 게임(`index.html` + `logic.js` + `game.js`)입니다.

- 7×9 판에 5가지 색 블록. 같은 색이 상하좌우로 **3개 이상** 붙어 있으면 눌러서 터뜨린다. 빈 자리는 위에서 채워진다
- 점수: 덩어리가 클수록 크게(8×개수 + (개수-3)^1.5). 1.6초 안에 이어서 터뜨리면 **콤보** 배수(최대 ×2). 3개 미만을 누르면 콤보가 끊긴다
- 💣 **폭탄**: 블록 25개를 터뜨릴 때마다 하나(최대 3개). 버튼을 누르고 블록을 고르면 그 블록의 가로·세로 한 줄이 같은 색으로 바뀐다 → 큰 덩어리를 만든다
- ⭐ **보너스 블록**: 가끔 나온다. 누르면 판에서 가장 많은 색을 모두 없앤다
- 🔥 **슈퍼 피버**: 점수 게이지가 차면 7초 동안 블록이 좌우에 큼직한 덩어리로 채워지고 점수 ×1.5
- 터뜨릴 덩어리가 하나도 없으면 판을 자동으로 섞는다
- 8,000점 동메달 · 16,000점 은메달 · 30,000점 금메달. 최고 점수는 `ppyongBest`
- 조작: 탭 / PC는 마우스, B 폭탄, P 일시정지, M 소리

원작의 같은 색 3개 이상 터뜨리기 규칙에서 아이디어를 얻었고, 점수·피버·판 크기 등 세부 규칙과 그림은 새로 만들었습니다.

규칙은 `logic.js`(화면 없이 Node 로 시험할 수 있다), 화면·입력·소리는 `game.js`.
